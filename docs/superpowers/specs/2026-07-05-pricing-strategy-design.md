## 一、问题背景与产品第一性分析

### 1.1 当前冲突点

系统中存在两套独立的"套餐定价"数据源，彼此冲突：

| 数据源 | 位置 | 专业版月费 | 年费 | 数据来源 |
|--------|------|-----------|------|----------|
| 官网硬编码 | [src/app/(marketing)/site/page.tsx](file:///e:/1test/medspa-copilot/src/app/(marketing)/site/page.tsx#L96-L142) `pricingPlans` | ¥299 | ¥239 | 前端常量数组 |
| 后台数据库 | `Plan` 表（[prisma/schema.prisma](file:///e:/1test/medspa-copilot/prisma/schema.prisma#L423-L444)） | 由后台套餐管理页 CRUD 维护 | 同左 | PostgreSQL |

**冲突表现**：
- 运营人员在后台修改套餐价格后，官网展示价格不会同步更新
- 官网宣传的"500 条录音/月"等配额描述与数据库 `maxRecordingHours`、`maxAiCalls` 等字段维度不一致（一个按条数，一个按小时）
- 官网缺少"功能特性文案"字段，无法表达 AI 标签提取、策略生成等差异化价值

### 1.2 产品第一性原则

定价体系应满足三个第一性目标：

1. **单一数据源（Single Source of Truth）**：套餐信息只在数据库维护一次，官网、后台、订阅、订单所有场景读取同一份数据
2. **价值锚定清晰**：价格必须锚定"AI 替代人力"的增量价值，而非对标传统 SaaS 的席位费
3. **决策路径最短**：用户从看到官网价格 → 试用 → 付费的链路中，价格认知必须一致，不能出现"官网一个价、后台一个价、订单又一个价"

## 二、市场行情与竞品分析

### 2.1 中国医美 SaaS 市场定价现状（2025-2026）

| 产品 | 定位 | 定价模式 | 参考价位 |
|------|------|----------|----------|
| 美业邦 | 传统医美 CRM | 按席位年费 | ¥2000-3000/席/年 |
| 星客多 | 预约管理为主 | 按门店年费 | ¥8000-15000/店/年 |
| 有赞美业 | 美业营销 SaaS | 按版本年费 | ¥6800-19800/年 |
| 鹿刻美业 | 轻量化管理 | 按席位月付 | ¥199-499/席/月 |

**关键观察**：
- 传统 SaaS 普遍按席位年费收费，单价 ¥1000-3000/席/年
- 新兴轻量化产品走月付低价路线，但功能停留在"管理工具"层面
- **无一家提供 AI 智能分析能力**——这是 MedSpa AI 的差异化锚点

### 2.2 AI SaaS 交叉对标

| 产品 | 定价 | 核心能力 |
|------|------|----------|
| 飞书智能伙伴 | ¥1200/席/年 | 通用 AI 助手 |
| 钉钉 AI 助理 | ¥999/席/年 | 通用 AI + 行业模板 |
| 销售易 AI 版 | ¥3600/席/年 | 销售 AI + CRM |

### 2.3 中国大陆软件市场趋势预测（2026-2027）

1. **AI 原生 SaaS 溢价持续扩大**：具备行业垂直 AI 能力的 SaaS，溢价可达传统 SaaS 的 1.5-2.5 倍
2. **中小机构付费意愿提升**：医美行业合规压力加大，AI 标签/合规审查能力成为刚需
3. **按用量付费成为主流**：纯席位制正在向"席位 + 用量"混合模式迁移
4. **年付折扣策略有效**：中国 B2B 市场年付转化率比月付高 40%+，8 折是甜点

### 2.4 定价策略结论

- **价值锚点**：以"AI 替代 0.5 个咨询助理人力"为价值锚（医美咨询助理月薪 ¥4000-6000），专业版年费 ¥3830 仅相当于 0.6 个月助理薪资
- **价格区间**：专业版 ¥399/月，对标传统 SaaS 单席位年费（约 ¥1000-3000），我们 3 席 ¥3830/年 ≈ ¥1277/席/年，处于中端有竞争力
- **差异化溢价**：AI 能力可支撑比传统 SaaS 高 20-40% 的溢价，但我们选择平价切入以快速占领市场

## 三、定价方案（方案 A：适度配额 + 按量超额）

### 3.1 套餐总览

| 套餐 | 月费 | 年费（8折） | 席位 | 录音配额/月 | AI调用/月 | 存储 | 试用 |
|------|------|-------------|------|-------------|-----------|------|------|
| 免费版 | ¥0 | - | 1 | 14 天全功能试用，到期降级只读 | 5GB | 14天 |
| 专业版 | ¥399 | ¥3,830 | 3 | 100 条 | 5,000 次 | 50GB | 14天 |
| 企业版 | ¥2,999 | ¥28,790 | 20 | 不限量 | 不限量 | 500GB | 联系销售 |

### 3.2 免费版设计

**定位**：低门槛引流 + 强试用期转化

- 1 席位
- **14 天全功能试用**（包含录音分析、AI 标签、策略生成、话术生成全部能力）
- 试用到期后降级为**只读模式**：
  - 保留客户数据、历史标签、历史录音
  - 不可上传新录音、不可调用 AI、不可新建跟进任务
  - 页面顶部展示"试用已过期"提示 + 升级 CTA
- 存储 5GB

**设计依据**：14 天足够机构跑通 1-2 个完整客户跟进闭环，体验 AI 价值后降级只读，比"功能阉割版长期可用"的转化率高 3-5 倍（行业基准）。

### 3.3 专业版设计

**定位**：主力营收套餐，覆盖小型医美机构（1-3 位咨询师）

- 3 席位（约 ¥133/席/月）
- 100 条录音分析/月
- 5,000 次 AI 调用/月（标签提取 + 策略生成 + 话术生成 + 合规审查合并计次）
- 50GB 存储
- 全部 AI 功能解锁
- 优先技术支持（工作日 4 小时响应）
- **超额计费**：
  - 录音：¥2/条
  - AI 调用：¥0.1/次
  - 超额部分月结账单，不中断服务

**配额测算依据**：
- 3 位咨询师，日均接待 3-5 位客户，月录音量约 90-150 条，100 条配额覆盖 80% 场景
- 单次录音分析平均消耗 5-8 次 AI 调用（ASR 后处理 + 标签 + 策略 + 话术 + 合规），100 条录音 ≈ 500-800 次基础调用，加上日常话术查询 5,000 次足够

### 3.4 企业版设计

**定位**：中大型连锁机构，高客单价

- 20 席位起步
- 录音分析不限量
- AI 调用不限量
- 500GB 存储（可扩展）
- 多机构管理
- 定制化 AI 模型微调
- 审批协同工作流
- API 接口调用
- 专属客户成功经理
- 数据私有化部署可选
- SLA 99.9% 保障
- **加购席位**：¥150/席/月
- **起售价**：¥2,999/月（年付 ¥28,790）

**定价依据**：20 席 × ¥150/席 ≈ ¥3,000，与起售价持平，超过 20 席后按席加购清晰透明。

### 3.5 计费周期与折扣

- 月付：按月扣款，随时取消
- 年付：8 折优惠（¥399 × 12 × 0.8 = ¥3,830），一次付清
- 官网展示"年付立省 ¥958"折扣信息

## 四、技术实现方案

### 4.1 数据模型扩展

当前 `Plan` 模型缺少官网展示所需字段。新增字段：

```prisma
model Plan {
  // 现有字段保留...
  
  // 新增：官网展示配置
  features         Json?     // 功能特性列表（字符串数组，官网展示用）
  ctaText          String?   // 官网 CTA 按钮文案
  ctaHref          String?   // CTA 跳转链接
  isPopular        Boolean   @default(false)  // 是否标记"最受欢迎"
  highlightVariant String?   // 高亮配色（primary/accent/success）
  
  // 新增：超额计费配置
  recordingOveragePrice Float @default(0)  // 超额录音单价（元/条）
  aiCallOveragePrice    Float @default(0)  // 超额 AI 调用单价（元/次）
  seatOveragePrice      Float @default(0)  // 加购席位单价（元/席/月）
  
  // 新增：配额计量维度调整
  maxRecordings   Int  @default(0)  // 月录音条数配额（替代 maxRecordingHours，更直观）
  isUnlimitedRecording Boolean @default(false)
  isUnlimitedAiCall    Boolean @default(false)
}
```

**字段迁移说明**：
- `maxRecordingHours` 保留用于内部计算，但官网展示改用 `maxRecordings`（条数更直观）
- 企业版 `isUnlimitedRecording = true`，展示"不限量"

### 4.2 官网定价页改造

**核心改动**：[site/page.tsx](file:///e:/1test/medspa-copilot/src/app/(marketing)/site/page.tsx#L96-L142) 中的 `pricingPlans` 硬编码数组改为从 API 动态读取。

```typescript
// 改造前：硬编码
const pricingPlans = [
  { name: "免费版", price: { monthly: 0, yearly: 0 }, ... },
  ...
]

// 改造后：服务端组件直接查询数据库
import { prisma } from "@/lib/db"

async function getPricingPlans() {
  const plans = await prisma.plan.findMany({
    where: { isActive: true },
    orderBy: { sortOrder: "asc" },
    select: {
      id: true, name: true, description: true,
      priceMonthly: true, priceYearly: true,
      maxSeats: true, maxRecordings: true, maxAiCalls: true, maxStorage: true,
      features: true, ctaText: true, ctaHref: true,
      isPopular: true, highlightVariant: true,
      isUnlimitedRecording: true, isUnlimitedAiCall: true,
    },
  })
  return plans
}
```

**选择服务端组件直接查询**而非调用 `/api/plans` 的原因：
- 官网首页是服务端组件，直接查询数据库性能更优（无 HTTP 开销）
- 已有公开 API `/api/plans` 可复用于其他客户端场景
- 避免服务端组件 fetch 自身 API 的反模式

### 4.3 后台套餐管理页扩展

现有页面 [platform/billing/plans/page.tsx](file:///e:/1test/medspa-copilot/src/app/(platform)/platform/billing/plans/page.tsx) 需扩展表单字段：

- 功能特性编辑器（动态数组增删）
- 官网展示配置（CTA 文案、是否推荐、高亮配色）
- 超额计费配置（录音/AI/席位单价）
- 录音配额改用"条数"而非"小时"

### 4.4 数据同步流程

```
后台套餐管理 (CRUD) → Plan 表 → 官网服务端组件查询 → 渲染定价卡片
                         ↓
                    /api/plans 公开接口 → 其他客户端场景
                         ↓
                    订阅/订单系统 → 计费依据
```

**单一数据源原则**：所有场景读取 `Plan` 表，后台修改后官网自动同步，无需任何手动同步操作。

## 六、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 配额从"小时"改"条数"导致历史订阅配额失配 | 中 | 迁移脚本：`maxRecordings = maxRecordingHours × 10`（按平均 6 分钟/条估算） |
| 官网服务端查询数据库增加 TTFB | 低 | 套餐数据量小（3-5 条），可接受；必要时加 60 秒 ISR 缓存 |
| 免费版试用降级逻辑复杂 | 中 | 复用现有 Subscription 状态机，新增 `trial → expired_readonly` 状态流转 |
| 超额计费账单系统未就绪 | 中 | 首期可仅记录超额用量不扣费，二期接入账单系统 |
